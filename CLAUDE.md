# Code Style

No comments in generated code. Good code explains itself.

The only exception is a comment that is genuinely impossible to understand without one — e.g. a non-obvious protocol quirk, an external spec reference, or unintuitive math. If you're about to write a comment that restates what the code already says, delete it.
